# Internationalization

Aedicule is in the **prepare** phase while the host and AVP surfaces are still
changing. English must be structurally complete. Missing translated catalogs
remain loud but non-fatal until the interface stabilizes and independently
reviewed translations can make completeness a build gate.

The canonical locale set is:

`am ar az bg bn bs da de el en es fa fi fil fr ha he hi hr hu id ig is it ja km ko mk nb nl pa pl ps pt_br ro ru sl sq sr sv sw ta th tr uk ur vi yo zh_hans zh_hant`

The five right-to-left locales are `ar he fa ps ur`. Locale resolution uses
longest boundary-aware matches, preserves `fil` and multi-segment codes, and
folds generic Chinese region tags deterministically to Simplified or
Traditional script.

This selection combines high-computer-penetration languages with deliberately
under-served languages such as Hausa, Amharic, Yoruba, Igbo, and Filipino. It
is an adoption and access baseline, not a ranking by speaker population.

The WAT ABI carries stable numeric action IDs and UTF-8 labels; locale handling
is a host responsibility and does not change application logic.
